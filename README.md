## 📖 Sobre o projeto

Este repositório documenta minha jornada de aprendizagem na disciplina **Desenvolvimento Front-End para Web** (Universidade Cruzeiro do Sul, 2026/2). Ele serve para:

- acompanhar a evolução dos estudos, aula a aula;
- praticar os conceitos vistos em sala com exemplos executáveis;
- consolidar o aprendizado em três projetos autorais, cada um focado em uma etapa do curso;
- manter um histórico organizado e versionado com Git e GitHub.

Trata-se de um **repositório pessoal de estudos**: os arquivos são exercícios e projetos acadêmicos, não produtos comerciais.

### 🎯 Objetivos de aprendizagem

- Estruturar páginas com HTML5 semântico.
- Estilizar interfaces com CSS3, incluindo layouts com Flexbox e Grid.
- Adicionar interatividade e lógica com JavaScript no navegador.
- Organizar projetos em pastas e versioná-los com Git.

## 🧰 Tecnologias utilizadas

| Tecnologia | Onde aparece |
|------------|--------------|
| **HTML5** | Todas as aulas e projetos: tags básicas, tabelas, listas, links, imagens, formulários, vídeo, áudio e elementos semânticos (`article`, `section`, `header`, `nav`, `main`, `aside`, `footer`). |
| **CSS3** | Aulas 06 a 09 e Projetos 2 e 3: CSS externo, classes e IDs, Flexbox, Grid, variáveis CSS, transições, media queries e tema claro/escuro. |
| **JavaScript** | Aulas 05, 09 e 10 e Projeto 3: seleção de elementos (DOM), eventos, condicionais (`if`, `switch`), laços (`for`) e *template strings*. |
| **Git e GitHub** | Controle de versão e hospedagem de todo o código. |
| **Google Fonts** | Fontes web carregadas via `@import` na [Aula 08](Aula08/). |

> Não há frameworks, bibliotecas ou ferramentas de build: todo o código é HTML, CSS e JavaScript puros.

## 🚀 Projetos desenvolvidos

Cada projeto possui um README próprio com mais detalhes.

### 1️⃣ Projeto 1: Site pessoal em HTML5

📂 [`Aula-Projeto/`](Aula-Projeto/) · 📄 [README do projeto](Aula-Projeto/README.md)

Site pessoal com página principal (apresentação, interesses, objetivos, tabela de conhecimentos, áudio, links externos e formulário de contato demonstrativo) e uma página dedicada ao hobby por videogames, ligadas entre si por links.

**Tecnologias:** HTML5 (semântica, links internos e externos, imagens, áudio, tabelas e formulários).

### 2️⃣ Projeto 2: Nexo Tech (Interface Express)

📂 [`projeto2_interface_express/`](projeto2_interface_express/) · 📄 [README do projeto](projeto2_interface_express/README.md)

Landing page sobre tecnologia, programação e Inteligência Artificial, com tema escuro, cabeçalho com menu de navegação, seção de apresentação, cards informativos e formulário demonstrativo (sem envio de dados).

**Tecnologias:** HTML5 e CSS3 (variáveis CSS, Flexbox, Grid, gradientes, transições, `clamp()` e media queries).

### 3️⃣ Projeto 3: Descubra seu caminho no Front-End

📂 [`Projeto3_javascript/`](Projeto3_javascript/) · 📄 [README do projeto](Projeto3_javascript/readme.md)

Painel interativo em que a pessoa informa o nome, escolhe uma área de interesse (HTML, CSS ou JavaScript) e recebe uma orientação de estudos exibida na página. Inclui validação do campo de nome, alternância entre tema claro e escuro, atalho com a tecla Enter e layout responsivo.

**Tecnologias:** HTML5, CSS3 (variáveis, Flexbox, Grid, media queries) e JavaScript (DOM, eventos, `switch`, *template strings* e `classList.toggle()`).

## 💻 Como executar os projetos

### Requisitos

- Um navegador atualizado (Chrome, Edge, Firefox ou similar).
- Conexão com a internet para carregar recursos externos (fontes do Google Fonts na Aula 08 e algumas imagens e vídeos hospedados em outros sites).
- [Git](https://git-scm.com/) para clonar o repositório (opcional: também é possível baixar o ZIP pelo botão **Code** do GitHub).

Não é necessário instalar dependências, usar Node.js ou subir um servidor.

### Passo a passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/alvaromarqurs-source/Frontend-web-development.git
   cd Frontend-web-development
   ```

2. Acesse a pasta da aula ou do projeto desejado.
3. Abra o arquivo HTML no navegador com um duplo clique ou pelo menu **Abrir arquivo**.

| Para ver... | Abra |
|-------------|------|
| Projeto 1 | `Aula-Projeto/projeto.html` |
| Projeto 2 | `projeto2_interface_express/index.html` |
| Projeto 3 | `Projeto3_javascript/index.html` |
| Qualquer exercício | O arquivo `.html` dentro da pasta `AulaXX/` |

> 💡 Mantenha os arquivos CSS, JavaScript e de mídia na mesma estrutura de pastas do repositório, pois os HTML os referenciam por caminhos relativos.

### Observações

- Em [`Aula03/exemplo-aula-02.html`](Aula03/exemplo-aula-02.html), a primeira imagem aponta para `img/Ápietat.webp`, arquivo que não está no repositório; a segunda imagem é carregada de uma URL externa.
- Em [`Aula05/exemplo-de-aula02-video.html`](Aula05/exemplo-de-aula02-video.html), o primeiro vídeo usa um arquivo local e o segundo depende de um link externo.

## 📈 Aprendizagem e evolução

O repositório segue uma progressão natural em três etapas:

| Etapa | Aulas e projetos | Competências trabalhadas |
|-------|------------------|--------------------------|
| **1. Estrutura com HTML** | Aulas 02 a 05 e Projeto 1 | Anatomia das tags, títulos, listas, tabelas, links, imagens, HTML semântico, formulários, vídeo e áudio. |
| **2. Estilo e layout com CSS** | Aulas 06 a 08 e Projeto 2 | CSS externo, classes e IDs, modelo de caixa, Flexbox, Grid, variáveis CSS, efeitos `:hover`, responsividade com media queries. |
| **3. Interatividade com JavaScript** | Aulas 09 e 10 e Projeto 3 | Scripts no HTML e em arquivo externo, DOM, eventos, validação de dados, condicionais, laços de repetição e alternância de tema. |

Essa evolução aparece também no código: os primeiros exemplos têm poucas linhas de HTML puro, enquanto o Projeto 3 já separa estrutura, estilo e comportamento em arquivos próprios (`index.html`, `css/` e `js/`).
