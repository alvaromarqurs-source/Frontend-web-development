# 💻 Projeto 4 – Interface Responsiva com Bootstrap

Projeto desenvolvido durante o curso **Desenvolvimento Front-End para Web**, com o objetivo de praticar a criação de páginas responsivas utilizando HTML e Bootstrap 5.

## 📌 Sobre o projeto

O projeto consiste em uma vitrine fictícia chamada **Vitrine Tech**, que apresenta três oficinas relacionadas ao desenvolvimento web:

- **HTML:** Oficina de HTML Semântico.
- **CSS:** Oficina de Layout com Bootstrap.
- **JavaScript:** Oficina de JavaScript Inicial.

A página foi desenvolvida com foco em organização, responsividade e utilização das classes prontas do Bootstrap.

## 🛠️ Tecnologias utilizadas

- HTML5
- Bootstrap 5.3.8
- CSS do Bootstrap via CDN

## 📱 Responsividade

Foi utilizado o sistema de grid do Bootstrap para adaptar a página a diferentes tamanhos de tela:

| Dispositivo | Organização |
|---|---|
| Celular | 1 card por linha |
| Tablet | 2 cards por linha |
| Computador | 3 cards por linha |

## 🎨 Recursos do Bootstrap utilizados

- `container` e `row`
- `col-12 col-md-6 col-lg-4`
- `card` e `card-body`
- `badge` e `text-bg-primary`
- `btn` e `btn-primary`
- Classes de cores, espaçamento, alinhamento e aparência.

## 📚 O que aprendemos

Durante o desenvolvimento, exploramos duas classes adicionais do Bootstrap:

**1. fw-semibold**

Utilizada nos títulos dos cards para aplicar um peso intermediário à fonte, deixando os títulos mais destacados.

**2. d-grid**

Utilizada nos elementos que envolvem os botões dos cards, fazendo com que eles ocupem toda a largura disponível.
