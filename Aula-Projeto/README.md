# 🌐 Projeto 1 — Desenvolvimento Front-End para Web

Projeto desenvolvido para a disciplina de **Desenvolvimento Front-End para Web**, utilizando **HTML5** para a criação de um site pessoal.

O projeto apresenta informações sobre mim, meus interesses, objetivos de aprendizagem, estudos e projetos, além de uma página dedicada ao meu hobby por videogames.

## 📌 Sobre o Projeto

O site foi desenvolvido com o objetivo de praticar conceitos fundamentais de **HTML**, estruturação de páginas, navegação entre documentos, utilização de imagens, áudio, tabelas, formulários e links externos.

A página principal apresenta informações pessoais, interesses relacionados à tecnologia e objetivos de aprendizagem.

Também foi criada uma página específica sobre videogames, destacando meu interesse por jogos como **Elden Ring** e **Dark Souls**.

## 🛠️ Tecnologias Utilizadas

* HTML5
* Estrutura semântica HTML
* Links e navegação entre páginas
* Imagens
* Áudio
* Tabelas
* Formulários
* Links externos

### 📄 `projeto.html`

Página principal do projeto, contendo:

* Apresentação pessoal
* Interesses e objetivos
* Estudos e projetos
* Tabela de tecnologias e conhecimentos
* Links para GitHub e LinkedIn
* Reprodução de áudio
* Formulário de contato demonstrativo

### 🎮 `paginas.html`

Página dedicada ao meu hobby por videogames, com destaque para **Elden Ring** e **Dark Souls**.

Também apresenta a experiência de conquistar o troféu de platina de Elden Ring após mais de 100 horas de jogo.

## 🎯 Objetivo

O principal objetivo deste projeto é colocar em prática os conhecimentos adquiridos durante as aulas de **Front-End para Web**, desenvolvendo uma página utilizando os recursos fundamentais do HTML.
